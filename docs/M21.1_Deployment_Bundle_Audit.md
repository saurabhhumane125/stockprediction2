## 2. Official Deployment Bundle Contract

To ensure absolute determinism and prevent production inference failures, the official deployment bundle contract must strictly contain only the files necessary for `ProductionInferenceEngine` to execute correctly.

Files like redundant metadata, reports, and plots are excluded from the production registry to keep the inference surface minimal.

**Contract Definition:**
```text
deployment_bundle.zip (or candidate directory)
├── manifest.json         # REQUIRED: Contains SHA-256 hashes, Target Strategy configs, and embedded metadata
├── best_model.keras      # REQUIRED: Keras model weights (or model.pt for PyTorch)
├── feature_scaler.pkl    # REQUIRED: Sklearn scaler for input normalization
└── calibrator.pkl        # REQUIRED: Isotonic/Platt scaler for mathematical probability calibration
```

*Note: The current implementation of `ProductionTrainingRunner` violates this contract by omitting `calibrator.pkl` and redundantly including `metadata.json` and `label_encoder.pkl`. These will need to be addressed in the subsequent implementation phase.*
